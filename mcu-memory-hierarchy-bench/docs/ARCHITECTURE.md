# Architecture

## Layers

| Layer | Folder | Depends on | Board-specific? |
|---|---|---|---|
| Tools | `tools/` | Python, numpy, TensorFlow | no |
| Models | `models/<model>/` | generated by `tflite2c.py` | no |
| Placements | `placements/<board>/<model>/s<KB>/` | generated by `make_placement.py` | yes (memory budget, offsets) |
| Engine | `core/engine/` | `port.h` (memory base addresses only) | no |
| Studies | `core/bench/` | `port.h`, `port_overheads.h` | no |
| Port | `ports/<board>/` | vendor headers, startup, linker script | yes |

A build = **one port + one study + (for model studies) one model + one placement**.

## The port contract (`core/include/port.h`)

| Function | Purpose |
|---|---|
| `port_init()` | clocks, cycle counter, console; enable FPU if present |
| `port_name()` | board id, printed in every CSV line |
| `port_cpu_hz()` | frequency used to convert cycles to time |
| `port_cycles()` | free-running 32-bit cycle counter (include a barrier if the core reorders) |
| `port_putc()`, `port_flush()` | console output |
| `port_extmem_init()` | bring up the slow tier; 0 = OK |
| `port_extmem_base()`, `port_extmem_bytes()` | slow-tier window used by placements |
| `port_memory_config()` | MPU / cache / memory attributes, applied once |
| `port_memory_desc()` | human-readable description, printed in the log |
| `port_scratch()` | fast scratch for the engine (≥ 32 KB) |
| `port_halt()` | stop after a run |

Optional (`core/include/port_overheads.h`, needed only by `overhead_bench`):

| Function | Purpose |
|---|---|
| `port_ov_buffer()` | fast-memory test buffer (and its size) |
| `port_ov_mpu_reprogram()` | one full MPU region reprogram, returns cycles |
| `port_ov_cache_clean_invalidate()` | timed D-cache clean+invalidate over a range |
| `port_ov_cache_clean()`, `port_ov_cache_invalidate()` | untimed helpers for coherence |
| `port_ov_dma_init()`, `port_ov_dma_copy()` | fast → slow DMA copy, returns cycles or `PORT_OV_FAIL` |

## Engine
- int8, NHWC, TFLite-exact requantisation (gemmlowp double rounding; half-up for conv/dwconv/fc, away-from-zero elsewhere).
- Ops: CONV_2D, DEPTHWISE_CONV_2D, FULLY_CONNECTED, ADD, MUL, MEAN, SOFTMAX, PAD, MAX_POOL_2D, QUANTIZE (float→int8, uint8→int8), DEQUANTIZE, RESHAPE.
- Every tensor is addressed through `nn_buf_ptr()`: SRAM arena offset or `port_extmem_base() + offset`, as given by the placement. Kernels compute in place in whichever tier the tensor lives.
- Weights stay where the linker puts them (internal flash on the current port).
- Uses DSP intrinsics (SMLAD/SXTB16) when `__ARM_FEATURE_DSP` is defined, portable C otherwise.

## Verification chain
1. `tflite2c.py` checks a numpy re-implementation against the TFLite interpreter, layer by layer and end to end.
2. Generated models carry a reference sum per layer; every study run checks all layers on the target before timing.
3. The output checksum must be identical across all placements of a model and across ports.
